## 💖 Funcionalidades Implementadas

### 1. Sistema Inteligente de Confirmação de Presença (RSVP)
- **Sem lista de presentes:** Atendendo ao pedido da família, a presença dos amigos e parentes é o único presente esperado.
- **Controle de Acompanhantes Adultos:** Registro do convidado e de acompanhantes adicionais.
- **Módulo de Crianças & Lembrancinhas (Pedido especial da Carina):**
  - Cadastro de cada criança com **Nome** e **Idade** (ex: 2 anos, 5 anos).
  - Cálculo exato do número de lembrancinhas necessárias para a faixa etária de cada pequeno príncipe ou princesa.
- **Integração WhatsApp:** Ao finalizar o RSVP, um botão gera o texto formatado completo pronto para envio direto para a Carina.
- **Passe Real Digital:** Confirmação visual em formato de passe real para o convidado guardar.

### 2. Trilha Sonora Oficial ("Festa das Gêmeas")
- Player de áudio flutuante com controles de Play, Pausa e Mudo.
- Abertura interativa do convite (*"Abrir Convite Real"*), respeitando as diretrizes de autoplay dos navegadores.
- Modal com a letra completa da canção para cantar junto.

### 3. Localização & Agenda
- Botão direto para rota no **Google Maps**.
- Botão direto para rota no **Waze**.
- Botão para **Adicionar ao Google Agenda**.
- Botão para **Baixar lembrete de calendário (.ics)** compatível com Apple Calendar e Outlook.

### 4. Painel da Família / Carina
- Acesso discreto no rodapé da página.
- Resumo com total de adultos, total de crianças e a contagem exata de lembrancinhas.
- Lista completa das crianças agrupadas com nome e idade.
- Botão para copiar o resumo estruturado e enviar para o WhatsApp.
- Botão para exportar em planilha (Excel/CSV).

## 🚀 Como subir para a Vercel (1 Clique)

O código já está 100% configurado no GitHub e preparado para a Vercel:

1. Acesse seu painel no [Vercel](https://vercel.com/new).
2. Conecte com sua conta GitHub (`cronosmkt-agency`).
3. Selecione o repositório **`festa-princesas-laura-e-olivia`**.
4. Clique em **Deploy**!
5. O Vercel detectará automaticamente o Vite e publicará o site com domínio `.vercel.app`.
